# Priya Forensic Science Portfolio

A professional personal portfolio website for Priya, a B.Sc. (Hons) Forensic Science student at Geeta University.

## Main file

- `index.html` — main portfolio website

## Run locally

Open `index.html` in a browser, or use a local static server.

Example with VS Code:

1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Deploy on Vercel

1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Use the default settings for a static HTML project.
4. Deploy and open the public Vercel URL.
